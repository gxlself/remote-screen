# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment,
personal attacks, discriminatory language and publishing others' private information are not acceptable in
issues, pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately through GitHub
([@gxlself](https://github.com/gxlself)) or, for anything sensitive, through a
[private security advisory](https://github.com/gxlself/remote-screen/security/advisories/new), which only
maintainers can read. Reports are handled confidentially.

Maintainers may remove comments, commits, code, issues and other contributions that violate this code, and may
temporarily or permanently ban contributors, following the enforcement guidelines of the Contributor Covenant.
